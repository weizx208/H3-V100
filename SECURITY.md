# Security and privacy

Report security issues privately to the repository owner rather than opening a
public issue containing credentials, local paths, private workflows or model
artifacts.

Before publishing a log, remove user names, drive mappings, network share
addresses, prompts, model paths and custom-node inventories. This node does
not write performance reports, collect personal data, or transmit telemetry.
SOL uses transient kernel timings only to choose a safe execution route; those
measurements are not saved by the node.
